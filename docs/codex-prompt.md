# Codex 开发 Prompt

将下面内容直接发送给在 CREW 仓库中运行的 Codex。

---

请在当前 `ai-dev` 分支实现 CREW。先读取仓库 `AGENTS.md`、`docs/design.md` 和当前文件内容，遵守工程要求及既定产品行为。现有实现可以从零重新设计和编写，使用 Rust。

在当前模式中自行制定模块结构、状态模型、实现顺序和验证计划，然后持续实现、实际运行、测试并修正，直到当前设计正确运行。计划无需等待我批准。实现步骤可以分开检查，全部既定要求均须完成。专家人格和 skill 系统仅按设计文档保留 TODO。

快捷键未指定部分、库选择、模块划分、配置格式、默认值等自行决定，在 `docs/` 记录最终选择。只在需要改变既定行为、目标无法兼顾、缺少实际接入信息或遇到真正阻塞时询问我。不要把常规工程决策交回给我。

模型接入支持 OpenAI-compatible API，可配置 base URL、模型和 API key，供 session 共用。明确记录选用的具体接口协议、streaming 和 tool calling 要求，以及配置方法。使用真实模型服务验证；缺少凭据时报告具体缺项，继续处理其余可验证工作，不生成虚假联调结果。不得将凭据写入仓库、日志或提交。

重点保证以下行为：

- 多人通过 SSH 后连接共享 session；共享 tab、pane、布局及内容，各连接独立导航。
- 无人员权限模型、无负责人。操作者以边框颜色表示，观察者简称在右上角；无人操作时边框白色。
- session/tab 导航、终端输入、agent 对话、布局编辑和私有回看遵守设计文档。一个 pane 只有一个人类操作连接，终端与对话共用该位置；确认接替、断线释放及回看返回行为明确。
- tab agent 有且只有一个附属执行终端，可委派 pane agent；pane agent 仅可启动无 shell 的只读探测助手。工具集合落实层级限制。
- 主工作区展示脚本执行与文件修改，右侧 agent 区展示对话和工具记录。关闭右侧区域仍能看到执行详情；区域开关共享，窄屏覆盖由客户端尺寸决定。
- AI Bash、接管、命令中断选择、人工 shell 切换、`/resume` 状态检查及交接记录可靠运行。人对话时 AI 可执行，进入终端输入时暂停对应 AI。
- 编辑通过读取上下文和精确替换／补丁完成；实际写入、展示差异，撤销遵守后续修改限制。
- 对话草稿共享并记录编辑参与者；一条活动对话；新建和恢复对话启动新的 Bash，保留当前文件。切换前处理当前命令与子任务。
- 断线继续工作，记录和配置保存到项目 `.crew`；服务退出后不恢复运行任务。支持保留服务脱离 session 后继续运行，CREW 能完全退出，关闭过程不能误杀服务。
- 在常见 Ubuntu 服务器上方便启动，可接受少量合理依赖，避免复杂环境准备。

对命令追踪、Bash 状态识别、终端尺寸、服务脱离 session 等技术边界，先进行真实验证再确定实现。无法精确追踪时明确显示实际可知状态。尚未规定的行为应在保留设计目标的前提下自行确定；若存在实质矛盾，再询问我。

实际验证至少覆盖：两个真实客户端独立导航与共享布局、输入占用接替、共享草稿、私有回看、断线重连、真实模型工具调用、文件修改与撤销、AI 接管与恢复、对话切换，以及 CREW 完全退出后保留服务仍运行。验证失败须修复；未验证项必须明确说明。

使用本地 Git 提交保存可检查的实现阶段，不推送、不创建 PR，不使用 Git 回滚。维护准确的 README、运行说明和验证记录，文档只描述最终有效行为。概念图用于理解界面意图，产品行为以设计文档为准。
